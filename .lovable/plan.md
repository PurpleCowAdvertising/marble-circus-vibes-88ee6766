# Site-wide partner header prominence

## Direction
Use the selected **Integrated partner eyebrow** treatment: a slim, refined sponsor rail associated with the existing header, using the real partner artwork and current black-and-gold styling.

## What will change
- Add a compact “Official Partners” rail to the shared header so it appears across all public pages.
- Display the existing partner logos in their established order, beginning with SABC 1, Gauteng Province, and Sport, Arts and Culture.
- Keep every existing sponsor link active; unlinked logos remain non-clickable.
- Preserve the current Scorpion Kings logo, navigation items, Subscribe action, collapsing desktop behavior, mobile bottom navigation, and all page layouts.
- On desktop, place the rail above the existing navigation as a low-profile eyebrow that visually belongs to the header.
- On mobile, use a smaller single-line logo rail at the top while leaving the floating bottom navigation unchanged.

## Behavior and polish
- Use a gentle horizontal flow so all 13 logos receive exposure without making the header oversized.
- Pause movement when hovered or focused, and stop animation for visitors who prefer reduced motion.
- Keep logos consistently sized despite their different proportions, without adding white boxes or backgrounds.
- Let the sponsor rail recede neatly as the desktop header condenses, preventing it from blocking page content.
- Retain the existing partner sections on the Home, Partners, and Contact pages unchanged.

## Verification
- Check the header on representative public pages at desktop and mobile sizes.
- Confirm logo order, click-through links, reduced-motion behavior, navigation access, and that no page content is obscured.
